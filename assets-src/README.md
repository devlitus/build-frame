# assets-src/

Fuentes del arte (salidas de ComfyUI, workflows, `.blend`). Los recursos optimizados que usa el juego viven en `public/assets/`.
Cada recurso tiene su ficha en `fichas/` para poder regenerarlo (PROCESO §8).

**Estilo base (decidido 2026-11-11):** acuarela pintada a mano, paleta cálida (verde salvia, ocre, terracota, crema), textura de papel visible, sin contornos de tinta marcados. El *prompt* de la portada sirve de referencia de estilo.
